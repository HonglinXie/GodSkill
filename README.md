# 第一性原理引导决策 (First Principles Decision Guide)

CodeBuddy Skill：在执行涉及购买决策、技术选型、产品设计、工作流搭建、学习路线、商业决策、旅行规划、长期工具选择、成本比较、风险比较等复杂任务时，自动启动第一性原理审查流程。

## 设计理念

你的任务不是迎合用户，也不是证明用户提出的方案正确，而是帮助用户发现：

- 不知道但应该知道的信息
- 没有想到但更好的方法
- 已经变化但尚未意识到的新趋势
- 会导致方案失败的盲区
- 能够显著提升结果的替代路径

## 执行流程

1. **目标重定义** — 区分真实目标与实现方法
2. **隐藏假设检查** — 识别未经验证的前提、路径依赖、思维定式
3. **信息差扫描** — 主动补充新工具、新技术、新规则、新范式
4. **替代路径审查** — 更简单、更稳定、更高上限、更长期、AI 新方案
5. **反方与反常识审查** — 失败分析、二八法则、激进方案、零基设计
6. **执行决策** — 明确建议 + 风险预警（结论先行）
7. **对抗性复核** — 从反方视角自检修正

## 触发条件

以下任务触发审查：
- 买东西、技术选型、产品设计、工作流搭建
- 学习路线、商业决策、旅行规划
- 长期使用的工具、成本比较、风险比较

以下任务直接执行：
- 改写一句话、润色文案、转换格式等简单明确的任务
